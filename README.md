# 🚗 CPM - سامانه خرید و فروش خودرو

یک پروژه‌ی ساده‌ی **PHP MVC** برای خرید و فروش خودرو.  
این پروژه به‌عنوان تمرینی برای درک بهتر معماری **MVC** در PHP ساخته شده و شبیه‌ساز یک بازار کوچک خرید و فروش خودرو است.

---

## ✨ امکانات
- 🔑 ثبت‌نام و ورود کاربر
- 🚘 افزودن، ویرایش و حذف آگهی خودرو
- 🔍 جستجو و مشاهده خودروهای موجود
- 📷 امکان آپلود تصویر خودرو
- 🛠️ ساختار ساده و تمیز MVC بدون استفاده از فریم‌ورک‌های خارجی

---

## 🗂️ ساختار پروژه
cpm/
┣ 📂 app/ # کنترلرها، مدل‌ها و ویوها
┣ 📂 public/ # نقطه ورود (index.php) و فایل‌های استاتیک
┣ 📂 config/ # تنظیمات پایگاه داده
┣ 📂 database/ # فایل‌های SQL
┗ README.md

---

## ⚙️ پیش‌نیازها
- نسخه PHP 7.4 یا بالاتر
- MySQL یا MariaDB
- وب‌سرور (Apache، Nginx یا PHP Built-in Server)

---

## 🚀 نصب و اجرا
1. کلون کردن مخزن:
   ```bash
   git clone https://github.com/danialchoopan/cpm.git


ایمپورت فایل SQL موجود در مسیر database/ داخل دیتابیس MySQL.

تنظیم اطلاعات پایگاه داده در فایل config/database.php.

اجرای سرور PHP:

php -S localhost:8000 -t public
باز کردن پروژه در مرورگر:
http://localhost:8000

📖 درباره پروژه
این پروژه صرفاً با هدف یادگیری و تمرین معماری MVC در PHP ساخته شده است.
کاربران می‌توانند خودروهای خود را برای فروش ثبت کنند و همچنین آگهی‌های موجود را مشاهده نمایند.
